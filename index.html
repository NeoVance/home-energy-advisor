Copy-paste embed code

Drop this where you want the widget to appear. Configure apiBase to your provisioned endpoint (we'll send it in your welcome email), and set branding.name to your site.

<!-- Home Energy Advisor widget -->
<div id="home-energy-advisor"></div>
<script src="https://neovance.github.io/home-energy-advisor/hea-widget.js"></script>
<script>
  HomeEnergyAdvisor.mount(document.getElementById('home-energy-advisor'), {
    apiBase: 'https://api.homeenergyadvisor.example',  // provided on signup
    apiToken: 'YOUR_PUBLISHNER_TOKEN',
    branding: { name: 'Your Site Name' },
    onConversion: function (e) { /* your analytics */ }
  });
</script>
OptionRequiredDescription
apiBaseYesProvisioned API endpoint (we supply it on signup)
apiTokenYesYour per-site publisher token
branding.nameNoSite name shown in the widget header
onConversionNoCallback fired on offer clicks for your analytics
